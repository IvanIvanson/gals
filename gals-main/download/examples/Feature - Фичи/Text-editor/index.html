About

This is the mobile version of the text editor. In this project, I tried to collect all my ideas from other projects, which I will talk about later in the text

Introduction

The text editor has the following elements:

  1. Text Position Menu and order list;

You can change the position of the text and create a order list

Just like in Windows Word, you can change the color of the text

You can see how to create it at this link:

component color text

Font and font size selection

Font styling

You can create a table. Click on the table icon, a block will appear to create a table. Here you can see how to create such a component:

table-component

Enter the number of rows and columns, then click on the table icon

To delete a table, click the trash can icon

You can create and save images by clicking the brush icon

A block will appear to create a picture

You can insert links and images into the text

In the drop-down list, select the button to create a link or insert an image

Paste the link to the picture, for example you can use this:

avatar.png

An image will appear. To change the size of the picture, you need to double-click on the picture, a modal window will appear to change the length, width and radius

You can circle the image and then remove the original image, in order to remove the source, click on the search icon

Click save "floppy disk", a modal window with a preview will appear

Click on the upload button, the file will be automatically downloaded and the code base64. You can copy the code base64 and paste it into your projects

Similarly, you can insert a link into your text
