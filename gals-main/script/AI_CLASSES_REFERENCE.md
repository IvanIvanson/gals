# GALS AI Reference: Классы, Брейкпоинты и Хелперы

Этот справочник оптимизирован для ИИ-агентов. Используйте эти классы при генерации кода для GALS.

## 1. Брейкпоинты (Адаптивность)
| Имя | Диапазон ширины | Описание |
|-----|-----------------|----------|
| `xxs` | 0px – 375px | Сверхмалые устройства (мобильные телефоны) |
| `xs`  | 376px – 425px | Малые устройства (большие телефоны) |
| `s`   | 426px – 770px | Средние устройства (планшеты) |
| `m`   | 771px – 1025px | Средние-большие (маленькие ноутбуки) |
| `l`   | 1026px – 1439.98px | Большие устройства (десктопы) |
| `xl`  | 1440px и выше | Сверхбольшие устройства (широкие экраны) |

*Пример использования:* `<div class="col-s-12 col-m-6 col-l-4">` (на мобильных 100%, на планшетах 50%, на десктопе 33%).

## 2. Утилиты отступов (Spacing)
Формат: `{свойство}{сторона}-{размер}`
- **Свойства**: `p` (padding), `m` (margin)
- **Стороны**: `t` (top), `b` (bottom), `l` (left), `r` (right), `x` (left & right), `y` (top & bottom)
- **Размеры**: `0`, `1` (0.25rem), `2` (0.5rem), `3` (1rem), `4` (1.5rem), `5` (3rem), `auto`

| Класс | CSS-эквивалент |
|-------|----------------|
| `pt-3` | `padding-top: 1rem` |
| `mb-2` | `margin-bottom: 0.5rem` |
| `px-4` | `padding-left: 1.5rem; padding-right: 1.5rem` |

## 3. Сетка (Grid)
| Класс | Описание |
|-------|----------|
| `.container` | Фиксированный по ширине центрированный контейнер |
| `.container-fluid` | Контейнер на всю ширину экрана (100%) |
| `.row` | Flex-обертка для колонок |
| `.col` | Автоматическая колонка, занимающая доступное пространство |
| `.col-{breakpoint}-{size}` | Колонка заданной ширины (например, `.col-m-6` = 50% на экранах `m` и выше) |

## 4. Хелперы и Компоненты
| Класс | Описание |
|-------|----------|
| `.visually-hidden` | Скрывает элемент визуально, но оставляет его доступным для скринридеров |
| `.badge` | Базовый стиль бейджа |
| `.badge-stable` | Зеленый бейдж (успех/стабильно) |
| `.badge-partial` | Желтый бейдж (частично/внимание) |
| `.badge-planned` | Красный бейдж (запланировано/ошибка) |
| `.badge-draft` | Фиолетовый бейдж (черновик) |
