# GALS: справочник для ИИ-агентов

> **Этот файл больше не является источником истины.**
> Прежняя версия описывала API, которого в GALS нет (`.row`, `.col-{bp}-{n}`,
> `mb-4`, `px-2`, `.visually-hidden` в составе фреймворка) — агенты генерировали
> по нему неработающий код.

## Куда смотреть

| Задача | Файл |
|--------|------|
| Быстрое понимание фреймворка | [`llms.txt`](../../llms.txt) — сетка, брейкпоинты, компоненты, правила |
| Точный список классов | [`llms/gals-classes.json`](../llms/gals-classes.json) — генерируется из `gals/gals.css` |
| Живые примеры | [ivanivanson.github.io/gals](https://ivanivanson.github.io/gals/) |

JSON — единственный источник истины по классам. Он собирается скриптом
`npm run build:llms` и проверяется тестами, поэтому не расходится со сборкой.

## Три вещи, которые нельзя выдумывать

1. **Сетка.** `.container` → `.container-block` с классом `pt-N`. Классов `.row`
   и `.col-*` в GALS нет. `pt-*` работают только внутри `.container`.
2. **`pt-*` — это колонки, а не отступы.** `pt-3` означает «ширина 3/12».
   Утилит отступов в GALS нет, кроме `.padding-lg`.
3. **Не придумывайте классы.** Если класса нет в `llms/gals-classes.json`, его не
   существует — напишите CSS сами, опираясь на переменные из `:root`.

## Сетка в двух строках

```html
<div class="container">
  <div class="container-block pt-6 pt-s12">50% на десктопе, 100% на планшете</div>
  <div class="container-block pt-6 pt-s12">...</div>
</div>
```

Брейкпоинты: `xl` (≥1440px), `l` (≤1439.98px), `m` (≤1025px), `s` (≤770px),
`xs` (≤425px), `xxs` (≤375px). Скрыть элемент на экране: `pt-{bp}-d_n`.
