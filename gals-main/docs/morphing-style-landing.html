Morphing style landing

Stable

Одностраничник в нейроморфном стиле: CSS-переменные в обёртке, :has() вместо JS для переключателей, clamp() для заголовка. Каждый блок — готовая секция.

Usage

<div class="neu-landing">
  <header class="nl-header">
    <div class="nl-brand"><span class="nl-mark">S</span>Softly</div>
    <nav class="nl-nav"><a href="#nl-feat">Features</a><a href="#nl-demo">Demo</a></nav>
  </header>

  <section class="nl-hero">
    <h1>Soft UI <b>next generation</b></h1>
    <p>Neumorphic components: buttons, toggles and sliders.</p>
    <a class="nl-btn nl-btn-primary" href="#nl-demo">Try it</a>
  </section>

  <section class="nl-features" id="nl-feat">
    <div class="nl-feature">
      <div class="nl-icon">&#10022;</div>
      <h3>Soft shadows</h3>
      <p>Two-direction shadows create depth.</p>
    </div>
  </section>

  <section class="nl-panel" id="nl-demo">
    <h2>Interactive slider</h2>
    <div class="nl-slider-wrap">
      <input type="range" min="0" max="100" value="50"
             oninput="document.getElementById('nl-out').textContent = this.value">
      <span class="nl-bubble" id="nl-out">50</span>
    </div>
  </section>
</div>

Notes

В исходном коде был :root — переменные --accent и другие перекрывали токены страницы документации. Переменные перенесены на обёртку .demo-nl.

В исходном коде были селекторы html, body { margin:0 } и * { box-sizing } — внутри страницы документации это ломает вёрстку сайта. Все селекторы скоуплены.

Класс .btn в исходнике совпадал с GALS .btn и переопределял его — переименован в .demo-nl-btn. Аналогично .feature, .icon, .nav, .demo.

Переключатели управлялись JS (classList.toggle). Заменено на чистый CSS :has(input:checked) — браузерные чекбоксы дают фокус, клавиатуру и скринридер бесплатно.

Добавлены role="switch", aria-label и :focus-visible — скрытый через opacity:0 инпут без кольца фокуса делает навигацию вслепую невозможной.

Кнопки CTA (<a>) используют :active для вдавливания вместо JS setTimeout — :active работает мгновенно и не требует обработчика.

В исходном коде id="demo" совпадал с id секции «Live demo» страницы документации — заменён на nl-demo.
