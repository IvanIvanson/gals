Pagination

Stable

Numbered links for a list that spans requests.

Usage

<nav class="pagination" aria-label="Results">
  <a href="?p=4" aria-label="Previous">&#8249;</a>
  <a href="?p=4">4</a>
  <span aria-current="page">5</span>
  <a href="?p=6">6</a>
  <span aria-hidden="true">&#8230;</span>
  <a href="?p=20">20</a>
</nav>

Live demo

‹ 4 5 6 7 … 20

Notes

Ellipses are aria-hidden; the current page carries aria-current="page".

Infinite scroll destroys the footer and the sense of position. Use it where scrolling is the activity, not where results are.

Icon pill pagination

Пилюля с круглыми кнопочками-иконками: активная страница подсвечивается кольцом. Стрелки листают, иконки выбирают страницу напрямую.

<nav class="icon-pagination" aria-label="Results">
  <ul>
    <li><button class="pgi-nav" type="button" data-step="-1"
                onclick="shiftPagination(this, -1)">&#8249; Prev</button></li>
    <li><button class="pgi-num is-active" type="button" aria-current="page"
                aria-label="Home" onclick="selectPagination(this)">
          <svg viewBox="0 0 24 24" width="20" height="20" fill="currentColor" aria-hidden="true">
            <path d="M3 11.5 12 4l9 7.5V21h-6v-6h-6v6H3z"/>
          </svg>
        </button></li>
    <!-- …ещё страницы -->
    <li><button class="pgi-nav" type="button" data-step="1"
                onclick="shiftPagination(this, 1)">Next &#8250;</button></li>
  </ul>
  <p class="pgi-status" role="status">Page 1 of 5</p>
</nav>

Page 1 of 5

Стрелки листают по краям и отключаются, иконки выбирают страницу. Скринридер читает «Page N of 5».

В исходном jQuery .find('.pageNumber.active') вызывался после .addClass('active') — выбирались обе страницы, а на краю списка класс active попадал на стрелку Next, и пагинация навсегда застревала. Здесь индекс считается числом и зажимается краями.

jQuery (35 КБ gzip) убран целиком: переключение класса — это classList.toggle, а не повод тянуть библиотеку.

Класс .pagination в исходнике совпадал с GALS-классом и ломал бы обычную пагинацию на той же странице. Демо использует .demo-pgi-*.

Глобальные * { margin:0; padding:0 }, body { display:flex } и ul { … } внутри страницы документации обнулили бы отступы и списки всего сайта. Все селекторы скоуплены.

Ссылки <a href="#"> заменены на <button type="button">: страница не меняется — это действие, а не переход. Плюс пропало битое href="#"; return false; в разметке.

Font Awesome 4.7 (CDN) заменён на инлайновые SVG: нет внешнего запроса, иконки наследуют currentColor и не ломаются, если CDN недоступен.

Белый текст на #86ff3d даёт контраст ~1.6:1 — не читается. Активная страница залита тем же салатовым, но текст тёмный #123a05.

Иконка без текста непонятна скринридеру: у каждой кнопки aria-label, у текущей — aria-current="page", у счётчика — role="status".

-webkit-box-reflect — вендорная фича WebKit, в Firefox и Edge её нет. Убран; при желании верните как чистую decoration-надстройку.
