Dropdown menu

Stable

Выпадающее меню профиля: карточка раскрывается по клику на стрелку, список пунктов появляется плавно.

Usage

<div class="profile-card" id="profile">
  <div class="profile-head">
    <div class="profile-avatar">
      <img src="avatar.jpg" alt="">
    </div>
    <h2>Jane Doe<br><span>Website Designer</span></h2>
    <button class="profile-toggle" type="button" aria-expanded="false">&rsaquo;</button>
  </div>
  <ul class="profile-nav">
    <li><a href="#">Edit Profile</a></li>
    <li><a href="#">Inbox</a></li>
    <li><a href="#">Settings</a></li>
    <li><a href="#">Logout</a></li>
  </ul>
</div>

Live demo

Jane Doe
Website Designer

  • Edit Profile
  • Inbox
  • Settings
  • Support
  • Logout

Кликните стрелку: карточка раскрывается, список пунктов появляется.

Notes

Раскрытие через max-height — просто и предсказуемо. Для тяжёлых меню лучше grid-template-rows: 0fr / 1fr.

Кнопка несёт aria-expanded, состояние которого меняется синхронно с классом.

Иконки соцсетей заменены на SVG в data-URL — никакого Ionicons с CDN.
