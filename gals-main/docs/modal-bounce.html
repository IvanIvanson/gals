Modal bounce

Stable

Модалка с пружинной анимацией появления. Три варианта: stretch-in, stretch-up, stretch-out.

Usage

<button class="btn" onclick="modal.showModal()">Open</button>
<dialog id="modal" class="modal">
  <form method="dialog"><button class="btn">Close</button></form>
</dialog>

@keyframes squish-in {
  60% { transform: scale(.5, 1.6); }
  80% { transform: scale(.9, 1.3); }
  100% { transform: scale(1, 1); }
}

Live demo

This is a bounce modal.

Notes

Анимация только на <dialog>, backdrop не анимирован — так проще.

Форма с method="dialog" закрывает модалку по любой кнопке без JS.

Три варианта пружины — это три @keyframes с разной последовательностью scale.
