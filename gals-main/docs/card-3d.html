Card 3D

Stable

Три карточки, сложенные в стопку под углом, разворачиваются в ряд при наведении на контейнер.

Usage

<div class="deck">
  <div class="deck-card" style="--i:-1">
    <svg><!-- brush icon --></svg>
    Design
  </div>
  <div class="deck-card" style="--i:0">
    <svg><!-- code icon --></svg>
    Code
  </div>
  <div class="deck-card" style="--i:1">
    <svg><!-- rocket icon --></svg>
    Launch
  </div>
</div>

Live demo

Design
Code
Launch

Наведите на контейнер: карточки разворачиваются в ряд.

Notes

Позиция считается от CSS-переменной --i: один блок правил на все три карточки.

z-index: calc(-1 * var(--i)) — карточки уходят под соседей в правильном порядке.

На узком экране раскладка переключается в колонку — там же пригодится @media.
