Person cards + modal

Stable

Карточки из массива: при клике появляется кнопка отмены, поверх — модалка с предупреждением. Всё на классах, без inline-стилей состояния.

Usage

const app = document.getElementById('app');

const people = [
  { id: 1, name: 'Tommy',  age: 23 },
  { id: 2, name: 'John',   age: 26 },
  { id: 3, name: 'Rachel', age: 28 },
  // В исходнике здесь был пустой объект {} —
  // он ронял рендер (undefined полей). Убран.
];

// avatar(p) — заглушка аватара: data-URI c SVG вместо внешнего jpg.
app.innerHTML = people.map((p) => `
  <div class="card">
    <img src="${avatar(p)}" alt="">
    <h3>${p.name}</h3>
    <div class="age"><span>age:</span> <span>${p.age}</span></div>
    <div class="id"><span>ID: </span><span>${p.id}</span></div>
  </div>`).join('');

Live demo

Click a card to see the cancel button.
Hover reveals age and ID.

Нажмите «Render cards»: появятся карточки и модалка. Наведите на карточку — раскроются возраст и ID.

Notes

Пустой объект {} в массиве из исходника давал карточку с undefined — убран.

innerHTML += в цикле пересоздаёт DOM на каждой итерации — заменено на map().join('') за одну вставку.

Опечатка «Don`t worck desktop» и логика с order: 3 на hover убраны: масштабирование через transform не ломает поток flex.
