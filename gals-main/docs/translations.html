Translations

Draft

This documentation is written in English. Everything else is a translation of it.

Policy

A translated page is a copy of the English one with the prose replaced. Class names, code samples ' and token names stay untouched — translating an identifier breaks the page it describes.

Set the language

Put lang on <html> to the language you ship. Screen readers pick their pronunciation from it, and so does hyphenation.
