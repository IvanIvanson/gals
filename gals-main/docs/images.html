Images

Stable

One real behaviour: an image marked container-fluid is measured against its parent by gals.js and resized in pixels, on load and on every settled resize.

Usage

The script looks for img.container-fluid, reads the parent block and writes the result into the inline style. The parent needs a size of its own — a column class is enough.

<div class="container">
  <figure class="container-block pt-6">
    <img class="container-fluid" src="cover.svg" alt="Cover art">
  </figure>
</div>

What is measured

Parent clientWidth minus its computed horizontal padding. The result lands in style.width; style.height stays auto so the image keeps its aspect ratio. Inline style is deliberate: attributes would be overridden by the stylesheet and did nothing.

Runs onWhen
DOMContentLoadedfirst paint, or immediately if the DOM is already parsed
resize150ms after the last resize event
gals:refreshafter SPA-style content replacement

Caveats

A parent with zero width is skipped rather than collapsing the image to nothing, so an image inside a hidden tab keeps its natural size until it becomes visible. After injecting markup without a resize, dispatch gals:refresh (the documentation renderer does this for you).
