Breakpoints

Stable

Six fixed breakpoints, one prefix each. The prefix sits between pt- and the column number, and it is the only place where GALS talks about screen size.

Prefixes

PrefixMedia queryClasses
xlmin-width: 1440pxpt-xl1 … pt-xl12
lmax-width: 1439.98pxpt-l1 … pt-l12
mmax-width: 1025pxpt-m1 … pt-m12
smax-width: 770pxpt-s1 … pt-s12
xsmax-width: 425pxpt-xs1 … pt-xs12
xxsmax-width: 375pxpt-xxs1 … pt-xxs12

How they stack

Prefixes are independent, not mobile-first. Each one lives inside a single media query, so a class does nothing outside its own range and never inherits from a smaller one. Declare every range you care about:

<div class="container">
  <div class="container-block pt-6 pt-m12">half on desktop, full below 1025px</div>
</div>
Boundary at 1440px

The l block ends at 1439.98px and xl starts at 1440px, so exactly one of them matches at any viewport width. The base pt-* width still applies everywhere; prefixed classes override it.

Changing a breakpoint

Breakpoints are written as literal media queries in gals/gals.css, one block per prefix — there is no variable to override yet. Edit the six @media blocks and rebuild, or keep the shipped file and write your own range around the same column widths.
