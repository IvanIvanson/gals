Download GALS

Download grid.zip

GALS ships as two framework files and nothing else. No build step, no dependencies, no configuration.

Integrity: SHA-256 checksum for the archive. License: MIT.

Get the source

Grab the latest archive, or take the framework files straight from the gals/ folder of the repository.

gals/
    gals.css    /* the grid and helpers */
    gals.js     /* menu, dropdowns, accordion groups, scrollspy, fluid images */

What's inside

The archive contains the two framework files plus a README and the MIT license: the grid stylesheet with responsive columns and component styles, and the runtime script for the mobile menu, accordion groups, scrollspy and fluid images.

Use it

Drop the stylesheet into the <head> and the script right before the closing </body> tag. Everything else is plain HTML.

Alternatively, load GALS from the jsDelivr CDN — no download needed:

<link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/IvanIvanson/gals@v1.2/gals-main/cdn/gals.min.css">
<script src="https://cdn.jsdelivr.net/gh/IvanIvanson/gals@v1.2/gals-main/cdn/gals.min.js"></script>

See jsDelivr CDN on the Introduction page for production tips.

<style>*,*::before,*::after{box-sizing:border-box}</style>
<link rel="stylesheet" href="./gals/gals.css">
<script src="./gals/gals.js" defer></script>
